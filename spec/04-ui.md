## UI-002 Formatting
- Money: `Intl.NumberFormat("en-GB", { style: "currency", currency: settings.currency })` from minor units ÷ 100.
  Example: `123456` with EUR → `€1,234.56`.
- Percent: one decimal, `"45.0 %"`; when the denominator is 0 show `"—"`.
- Dates: `DD.MM.YYYY`.
- Money input: accepts `1234.56`, `1,234.56`, `1234,56` (last `,` or `.` followed by 1–2 digits is decimal);
  converted to minor units; more than 2 decimals is a validation error. Rule: the last `,` or `.` is always the
  decimal separator and must be followed by 1–2 digits; any earlier separators must be the other character and
  group exactly 3 digits. So `1,234` → error, `1.234` → error, `1.234,56` → 123456.
- VAT rate input: percent with up to 2 decimals (`20` → 2000 bp).

## UI-002a Common list behaviour (applies to UI-010, 020, 030, 040, 050)
- Table with sortable columns (click header toggles asc/desc); default sort defined per screen.
- Text search box (`data-testid="list-search"`), case-insensitive "contains" over the listed searchable columns.
- "Show archived" toggle (`data-testid="toggle-archived"`), off by default. Archived rows are shown greyed with an
  "Archived" badge.
- "New" button (`data-testid="btn-new"`) opens the create form (modal drawer).
- Row click opens the edit form for active rows; for archived rows opens a read-only view with a "Restore" button.
- Row action menu: Edit, Archive (with confirm dialog `data-testid="confirm-archive"`) / Restore.
- Empty state text: "No records match your search." when the search text is non-empty; otherwise (including when
  only other filters yield no rows) "No records yet."
- Each row has `data-testid="row-<id>"`.

## UI-002b Common form behaviour
- Forms open in a right-side drawer, title "New <Entity>" / "Edit <Entity>"; the read-only view of an archived record
  is titled "<Entity>" (e.g. "Investor").
- Field inputs have `data-testid="field-<camelCaseFieldName>"`.
- Save (`btn-save`) and Cancel (`btn-cancel`). Save disabled while submitting.
- Validation errors from use cases are shown under the matching field (`data-testid="error-<field>"`); errors
  without a field are shown as a red alert at the top of the form (`data-testid="form-error"`).
- On success: drawer closes, a toast "Saved" appears, the list refreshes.
- Pickers (select inputs) for parent entities list **active** records only, sorted by name / number. In edit forms the
  picker additionally shows the currently referenced parent even if archived.

## UI-030 Projects list
Columns: Name, Investor, Status (coloured badge), Deadline, Budget.
Searchable: name, investor name. Default sort: Deadline asc (nulls last).
Extra filters: Status multi-select (`filter-status`), Year select (`filter-year`, values from
`availableYears()`, plus "All years"; year rule = AN-3).
**UI-031 Project form:** name, investorId (picker), status (select, default PLANNED), deadline (date), budget (money).
**UI-032 Project detail** (route `/projects/:id`, opened via row action "Open"):
- Header: name, investor, status, deadline, budget. The screen title (`screen-title`) is the project name.
- Summary cards (all-years, net amounts): Contracted (INCOMING), Collected, Contracted to subcontractors (OUTGOING),
  Paid to subcontractors, Net (collected − paid). Until contracts (M3) and invoices (M4) exist, every card shows 0.
  Collected, Paid to subcontractors and Net include archived contracts and archived invoices.
- **UI-033** Budget realisation card (`card-realisation`): Budget, Collected, Realisation % of budget as a progress bar,
  Remaining budget — same formulas as AN-5 for this project. Hidden when the project has no budget.
- Tabs: Contracts (UI-040 list pre-filtered to this project), Invoices (UI-050 list pre-filtered to this project).
  The Contracts tab is the default tab. Contracts tab: the UI-040 list fixed to this project; `filter-project` is
  hidden, the Project column stays; search, `filter-type`, `toggle-archived` and `btn-new` are shown. "New" opens
  the create form with `projectId` preset and disabled; for an archived project "New" is hidden (BR-GEN-006). The
  summary cards reload after any save, archive or restore in the tab.
  Invoices tab: the UI-050 list fixed to this project; `filter-project` is hidden, the Project column stays; search,
  `filter-status`, `filter-type`, `toggle-archived` and `btn-new` are shown. "New" is shown also for an archived
  project (the invoice's parent is the contract); its contract picker lists only this project's active contracts.
  The summary cards reload after any save, archive, restore, status change or attachment change in the tab.

## UI-040 Contracts list
Columns: Number, Type (badge "In"/"Out"), Project, Counter-party (investor name for INCOMING, subcontractor name
for OUTGOING), Date, Value (net), Invoiced (sum of net values of non-cancelled invoices, archived invoices included), Paid (sum of net values of PAID
invoices, archived included).
Searchable: number, project name, counter-party name, description. Default sort: Date desc, then Number asc
(case-insensitive), then id.
Filters: Type (`filter-type`; labels "All" (`common.all`), "Incoming", "Outgoing"), Project (`filter-project`: first
option "All projects" (`common.allProjects`, default), then all projects including archived, sorted by name,
labelled with the project name).
**UI-041 Contract form:** type (segmented control, create only), projectId (picker, create only),
subcontractorId (picker, shown and required only when OUTGOING), number, date, value, description.
For INCOMING the form shows the project's investor as read-only text (`field-investorName`, label "Investor"); it
shows "—" until a project is selected and is also shown in edit/read-only view for INCOMING.
- Create form default type = INCOMING. Segmented labels from `enum.contractType.*` ("Incoming" / "Outgoing"); list
  badge text "In" / "Out". Switching the type to INCOMING clears the subcontractor.
- In the edit form and the read-only view, type and project are shown as disabled controls with the same test ids
  `field-type` / `field-projectId`.
- Archive confirm dialog names the contract by its number.
- Labels: Type, Project, Subcontractor, Investor, Number, Date, Value (net), Description. Drawer titles: "New Contract"
  / "Edit Contract" / "Contract".
- Error texts: `errors.contract.subcontractorRequired` "A subcontractor is required for outgoing contracts.";
  `errors.contract.subcontractorForbidden` "Incoming contracts cannot have a subcontractor.";
  `errors.contract.numberDuplicate` "This contract number is already used in this project.";
  `errors.immutable` "This field cannot be changed after creation."

## UI-050 Invoices list
Columns: Number, Direction ("In"/"Out" from contract type), Contract number, Project, Date, Due date, Net,
VAT %, Gross, Status (badge), Attachment (📎 icon if present; click opens the PDF).
Searchable: number, contract number, project name, description. Default sort: Date desc, then Number asc
(case-insensitive), then id.
Headers: Number, Direction, Contract, Project, Date, Due date, Net, VAT %, Gross, Status, Attachment.
Filters: Status (`filter-status`, multi-select as in UI-030, labels from `enum.invoiceStatus.*`), Direction
(`filter-type`; labels "All" (`common.all`), "Incoming", "Outgoing", as in UI-040), Project (`filter-project`,
as in UI-040).
VAT % column: basis points ÷ 100 with up to 2 decimals, trailing zeros dropped, then ` %` (2000 → "20 %",
950 → "9.5 %", 1225 → "12.25 %"); the UI-002 one-decimal percent rule does not apply.
Attachment column: 📎 icon `icon-attachment` when present.
Overdue highlight: status ISSUED and dueDate < today (local calendar date of `Clock`) → due date shown in red.
Status badge labels from `enum.invoiceStatus.*`: "Draft" / "Issued" / "Paid" / "Cancelled".
**UI-051 Invoice form:** contractId (picker showing `"<number> — <project> (In|Out)"`, create only), number, date,
dueDate, value (net), vatRate (default from settings), computed read-only VAT amount and Gross, status (select
offering only transitions allowed by BR-IVC-005 from the current status), description, attachment block (UI-053).
- Contract picker: active contracts only (including active contracts of archived projects), sorted by number
  (case-insensitive); option label `entity.invoice.contractOption` = "{{number}} — {{project}} ({{direction}})",
  direction "In" / "Out". In the edit form and the read-only view the contract is a disabled `field-contractId`.
- Status select options: current status first, then the allowed next statuses (BR-IVC-005) in enum order
  (create: current = DRAFT → "Draft", "Issued", "Cancelled").
- VAT amount and Gross are read-only texts `field-vatAmount` and `field-gross` (formatted money, UI-002), computed
  with `computeInvoiceAmounts`; "—" while net or VAT rate is invalid.
- Archive confirm dialog names the invoice by its number.
- Labels: Contract, Number, Date, Due date, Value (net), VAT rate (%), VAT amount, Gross, Status, Description,
  Attachment. Drawer titles: "New Invoice" / "Edit Invoice" / "Invoice".
- Error texts: `errors.invoice.numberDuplicate` "This invoice number is already used on this contract.";
  `errors.invoice.dueBeforeDate` "The due date cannot be before the invoice date.";
  `errors.invoice.statusTransition` "This status change is not allowed.";
  `errors.attachment.notPdf` "The file must be a PDF.";
  `errors.attachment.tooLarge` "The file must not be larger than 20 MB."
**UI-052** Under the contract picker show "Invoiced so far: X of contract value Y" and a yellow warning
(`warn-over-invoiced`) when saving would make the non-cancelled sum (archived invoices included) exceed the contract value.
Info line `info-invoiced`, text "Invoiced so far: {{invoiced}} of contract value {{value}}" (formatted money);
warning text "Saving this invoice will exceed the contract value."
**UI-053 Attachment block:**
- No attachment: "Attach PDF" button (`btn-attach`) → native file dialog filtered to `*.pdf`
  (browser mode: hidden `<input type="file" data-testid="input-attach">`).
- With attachment: file name link (`link-attachment`, opens in the OS viewer), "Replace" (`btn-replace`),
  "Remove" (`btn-remove-attachment`, with confirm dialog `confirm-remove-attachment`).
- Button labels: "Attach PDF" / "Replace" / "Remove". BR-IVC-006 errors are shown as `error-attachment`.
- The chosen file is checked against BR-IVC-006 as soon as it is chosen (`error-attachment` shown immediately, the
  file is not kept). On Save the invoice is created/updated first, then the file is stored or removed.
- Remove confirm dialog: title "Remove attachment", message "Remove the attachment “{{name}}”?", buttons
  "Remove" / "Cancel".
- An empty VAT rate field is sent as null (DM-050 defaults apply).
- In the create form, the chosen file is stored when the invoice is saved; in the edit form, attach/replace/remove
  take effect on Save. Cancel discards the change.

## UI-060 Analytics common
- Year selector (`filter-year`) at the top (UI-061 … UI-064): values from `availableYears()` (years that appear in any contract date
  or invoice date or project deadline, descending), default = current calendar year if present, else the latest year.
- Net/Gross toggle (`toggle-gross`) on UI-061, UI-062, UI-064; default Net. Contract values have no VAT; in Gross
  mode contract values are still shown net and the column header says "(net)".
- Tables have a footer row (`data-testid="table-footer"`) with totals as defined in `05-analytics.md`.
- Clicking a project name navigates to UI-032.

## UI-080 Settings
Fields: currency (select of EUR, RSD, USD, CHF, GBP), defaultVatRate (percent). Shows the DB file path and the
documents folder path (read-only, with "Open folder" button in Tauri mode). Save shows toast "Saved".
In browser mode both paths show "In-memory (browser mode)" (i18n key `settings.inMemory`) and "Open folder" is hidden.
