# M7 — Demo mode

## Scope (spec IDs)
OV-005, AR-007 (`src/app/demo/`), AR-009, AR-010 step 3a, AR-012 (demo smoke row), AR-013, DEMO-001 … DEMO-004,
DEMO-900 … DEMO-906, UI-003, UI-080, UI-081, UI-090, UI-091.
Regression: TC-M1-020 (shell), TC-M1-030, TC-M1-032 (smoke, live layout unchanged), TC-M6-001 (i18n key sets).

## Deliverables
- Rust (`src-tauri/src/lib.rs`):
  - profile resolution from `<root>/profile.json`;
  - demo reset at setup via the `.reset` marker;
  - fs scope limited to the active profile's `documents/`;
  - window title suffix in demo;
  - commands `get_data_dir` (profile dir), `get_profile`, `switch_profile`, `reset_demo`.
- `src/app/profile.ts` (`profileFromSearch`). `RuntimeInfo` gains `profile`, `switchProfile`, `resetDemo`.
  `composition.ts` chooses the profile per mode and runs the demo seed (AR-010 step 3a).
- `src/app/demo/`:
  - `demoDataset.ts`: DEMO-003 as data, with relative dates;
  - `resolveDemoDate.ts`: DEMO-002 date resolution and the +30-day due date;
  - `seedDemoData.ts`: DEMO-001, use cases only;
  - `assets/demo-invoice-a.pdf`, `assets/demo-invoice-b.pdf`: DEMO-004.
- UI: demo banner (UI-003), Settings demo section with switch and reset dialogs (UI-081), and the new i18n keys in
  `en.json` and `sr-Latn.json`.
- `scripts/smoke-mac.mjs`: the demo profile steps of AR-012. `.github/workflows/windows-build.yml`: step TC-M7-015.
- ESLint boundaries: `src/app/demo/**` may import only `src/core/**` and `src/app/**` (no `src/adapters/**`).
