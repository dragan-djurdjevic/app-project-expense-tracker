## Scope (spec IDs)
AN-000 … AN-4, AN-900 … AN-904, UI-060 … UI-064.

- `AnalyticsQuery` port implementation `SqliteAnalyticsQuery` (aggregation in SQL); use cases
  `getContractedVsCollected`, `getSubcontractorPayments`, `getProjectsInYear`, `getNetResult`, `getAvailableYears`.
- Pure core helpers for percentages and footer totals (AN-000d/e).
- Screens UI-061 … UI-064 with year selector, Net/Gross toggle, footer rows, expandable AN-2 rows.
- Fixture `"analytics"` exactly as AN-900 (`tests/fixtures/analytics.ts`), seedable in E2E.
