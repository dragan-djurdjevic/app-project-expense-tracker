# M2 — Investor, Subcontractor, Project CRUD

## Scope (spec IDs)
DM-010, DM-020, DM-030, BR-GEN-001 … BR-GEN-008, BR-INV-001, BR-SUB-001, BR-PRJ-001,
UI-002a, UI-002b, UI-010, UI-011, UI-020, UI-021, UI-030, UI-031, UI-032 (header + summary cards only;
the Contracts/Invoices tabs show "Coming in M3/M4").
Projects list Year filter (UI-030) uses the AN-3 rule; implement `projectsInYear` logic in `ProjectRepository.list`
(the AnalyticsQuery port stays for M5). `availableYears()` may be implemented in M2 as a repository/helper and
reused in M5.

## Deliverables
- Use cases per entity: `list`, `get`, `create`, `update`, `archive`, `restore`.
- `SqliteInvestorRepository`, `SqliteSubcontractorRepository`, `SqliteProjectRepository`.
- Screens UI-010/011, UI-020/021, UI-030/031/032.
- Test fixture `"basic"` in `tests/fixtures/basic.ts`: 2 investors, 2 subcontractors, 3 projects (1 archived),
  usable via `window.__TEST__.seed("basic")`.
- i18n keys for all new strings.
