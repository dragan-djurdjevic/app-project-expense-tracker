# M3 — Contract CRUD

## Scope (spec IDs)
DM-040, BR-CON-001 … BR-CON-005, BR-GEN-* (as applied to contracts), UI-040, UI-041,
UI-032 (Contracts tab + summary cards "Contracted" and "Contracted to subcontractors").

## Deliverables
- Contract use cases: `list`, `get`, `create`, `update`, `archive`, `restore`.
- `SqliteContractRepository` (list returns counter-party name, project name; "Invoiced"/"Paid" columns return 0
  until M4 provides invoices — implement the SQL now so M4 needs no change here).
- Screens UI-040/041; Contracts tab on project detail.
- Fixture `"basic"` extended with 4 contracts (2 INCOMING, 2 OUTGOING across 2 projects):
  - Villa Lake: INCOMING `V-001`, 2025-02-10, 10 000 000; OUTGOING `V-OUT-1` to Struct Eng, 2025-03-15, 3 000 000.
  - School Annex (archived project, contracts active): INCOMING `S-001`, 2026-01-20, 3 000 000; OUTGOING `S-OUT-1`
    to HVAC Pro, 2026-02-05, 800 000.
  - Office Tower has no contracts (keeps TC-M2-036 valid).
