# M4 — Invoice CRUD + PDF attachment

## Scope (spec IDs)
DM-050, BR-IVC-001 … BR-IVC-008, BR-GEN-* (as applied to invoices), DS-004, UI-050 … UI-053,
UI-032 (Invoices tab + summary cards "Collected", "Paid to subcontractors", "Net"), UI-040 Invoiced/Paid columns.

## Deliverables
- Invoice use cases: `list`, `get`, `create`, `update`, `archive`, `restore`, `changeStatus`,
  `attachDocument`, `removeDocument`, `openDocument`; pure function `computeInvoiceAmounts(value, vatRate)`.
- `SqliteInvoiceRepository`; `FsDocumentStorage` used in Tauri mode (DS-004).
- Screens UI-050/051/052/053; Invoices tab on project detail.
- Test PDFs in `tests/fixtures/files/`: `sample.pdf` (valid, < 100 KB, ASCII-only so the browser fixture can load it as text), `fake.pdf` (text file renamed),
  `image.png`. The > 20 MB case is generated in-memory in tests.
- Fixture `"basic"` extended with invoices covering all four statuses, one with an attachment (all VAT 2000):
  - On `V-001` (Villa Lake, INCOMING): `INV-001`, 2025-03-01, 4 000 000, PAID, due 2025-03-31, attachment
    `sample.pdf`; `INV-002`, 2025-06-01, 3 000 000, ISSUED, due 2025-06-30 (overdue); `INV-003`, 2025-07-01,
    1 000 000, DRAFT; `INV-004`, 2025-08-01, 500 000, CANCELLED.
  - On `V-OUT-1` (Villa Lake, OUTGOING): `SI-001`, 2025-04-10, 1 500 000, PAID.
  - Office Tower stays without invoices (keeps TC-M2-036 valid); all dates are in 2025 (keeps TC-M2-034 valid).
    Villa Lake cards: Collected €40,000.00, Paid to subcontractors €15,000.00, Net €25,000.00.
  - AR-009 `seed("basic")` also writes the attachment into `InMemoryDocumentStorage`, so the fixture function
    receives the document storage as well as the DB.
