# M6 — Serbian (Latin) language

## Scope (spec IDs)
OV-005, DM-060 (`language`), DS-002, DS-006, AR-007 (i18n folder), AR-010 step 3, AR-012 (migration versions),
UI-002, UI-050 (VAT % column decimal separator), UI-080, UI-090, UI-091.
Regression in M1 tests affected by DS-006: TC-M1-010, 011, 014, 030, 032.

## Deliverables
- `Settings.language` (`en` | `sr-Latn`, default `en`) in core domain, `updateSettings` validation, sqlite mapping.
- Migration `src/adapters/sqlite/migrations/0002_settings_language.sql` exactly as DS-006.
- `src/ui/i18n/sr-Latn.json` with the full key set of `en.json`, terms per UI-091; i18n registers both languages.
- Locale-aware formatting helpers (money, percent, VAT %) and sorting (UI-002); English output unchanged.
- Settings screen language select (UI-080), applied immediately on save; startup applies the stored language.
- Mantine `DatesProvider` locale per UI-090.
- `scripts/smoke-mac.mjs` and the CI smoke step expect migration versions `1`, `2`.
- E2E helper to switch the language via the Settings screen.
